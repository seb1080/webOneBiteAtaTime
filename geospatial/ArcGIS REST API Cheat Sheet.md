# ArcGIS REST API Cheat Sheet

| **Parameter Name**              | **Description**                                                     | **Data Type**             | **Example**                                                                                                   |
| ------------------------------- | ------------------------------------------------------------------- | ------------------------- | ------------------------------------------------------------------------------------------------------------- |
| **f**                           | Output format of the response.                                      | `string`                  | `f=json`, `f=geojson`, `f=pjson`                                                                              |
| **where**                       | SQL-like filter expression to select records.                       | `string`                  | `where=OBJECTID>100 AND MUNICIPALITE='Québec'`                                                                |
| **objectIds**                   | Comma-separated list of specific feature IDs to query.              | `string`                  | `objectIds=1,2,3,4`                                                                                           |
| **time**                        | Filter features by time or time range (if layer supports time).     | `integer` or `date range` | `time=1577836800000,1609459200000`                                                                            |
| **geometry**                    | Spatial filter geometry (point, line, polygon, or envelope).        | `JSON` or `string`        | `geometry={"x":-71.2,"y":46.8,"spatialReference":{"wkid":4326}}`                                              |
| **geometryType**                | Type of geometry used in the `geometry` parameter.                  | `string`                  | `geometryType=esriGeometryEnvelope`, `esriGeometryPolygon`                                                    |
| **inSR**                        | Spatial reference WKID of input geometry.                           | `integer`                 | `inSR=4326`                                                                                                   |
| **spatialRel**                  | Spatial relationship for filtering geometry.                        | `string`                  | `spatialRel=esriSpatialRelIntersects`, `esriSpatialRelContains`                                               |
| **relationParam**               | Relationship parameters for advanced spatial queries.               | `string`                  | `relationParam=mask:6409`                                                                                     |
| **outFields**                   | Comma-separated list of fields to return. Use `*` for all.          | `string`                  | `outFields=OBJECTID,LOT_NO,ADRESSE`                                                                           |
| **returnGeometry**              | Whether to return feature geometries.                               | `boolean`                 | `returnGeometry=true`                                                                                         |
| **maxAllowableOffset**          | Simplifies returned geometries for faster performance.              | `double`                  | `maxAllowableOffset=10`                                                                                       |
| **geometryPrecision**           | Number of decimal places for returned coordinates.                  | `integer`                 | `geometryPrecision=2`                                                                                         |
| **outSR**                       | Spatial reference WKID for the output geometries.                   | `integer`                 | `outSR=32198`                                                                                                 |
| **gdbVersion**                  | Version name if querying a versioned geodatabase.                   | `string`                  | `gdbVersion=SDE.DEFAULT`                                                                                      |
| **orderByFields**               | Field(s) used to sort the output results.                           | `string`                  | `orderByFields=OBJECTID ASC`                                                                                  |
| **groupByFieldsForStatistics**  | Fields to group results when using `outStatistics`.                 | `string`                  | `groupByFieldsForStatistics=MRC_CODE`                                                                         |
| **outStatistics**               | Defines server-side statistical operations (sum, count, avg, etc.). | `JSON`                    | `outStatistics=[{"statisticType":"count","onStatisticField":"OBJECTID","outStatisticFieldName":"lot_count"}]` |
| **having**                      | SQL HAVING clause applied to grouped results.                       | `string`                  | `having=lot_count>100`                                                                                        |
| **resultOffset**                | Offset (start index) for paginated results.                         | `integer`                 | `resultOffset=2000`                                                                                           |
| **resultRecordCount**           | Number of records to return (per page).                             | `integer`                 | `resultRecordCount=1000`                                                                                      |
| **returnCountOnly**             | Returns only the feature count instead of geometries.               | `boolean`                 | `returnCountOnly=true`                                                                                        |
| **returnExtentOnly**            | Returns only the extent (bounding box) of matching features.        | `boolean`                 | `returnExtentOnly=true`                                                                                       |
| **returnIdsOnly**               | Returns only the list of `OBJECTID` values.                         | `boolean`                 | `returnIdsOnly=true`                                                                                          |
| **returnDistinctValues**        | Returns unique records for specified `outFields`.                   | `boolean`                 | `returnDistinctValues=true`                                                                                   |
| **quantizationParameters**      | Used for generalized geometries or vector tiles.                    | `JSON`                    | `quantizationParameters={"extent":{"xmin":...},"mode":"view"} `                                               |
| **returnExceededLimitFeatures** | Controls return behavior when max record limit exceeded.            | `boolean`                 | `returnExceededLimitFeatures=true`                                                                            |
| **token**                       | Security token for accessing secured services.                      | `string`                  | `token=ABC123XYZ`                                                                                             |
| **datumTransformation**         | Defines datum transformations when projecting coordinates.          | `JSON`                    | `datumTransformation=[{"wkid":108190}]`                                                                       |
| **parameterValues**             | Dynamic layer query parameters (MapServer only).                    | `string`                  | `parameterValues=[{"parameterName":"area","value":"Capitale-Nationale"}]`                                     |
| **text**                        | Full-text search term across all searchable fields.                 | `string`                  | `text=Rue Saint-Jean`                                                                                         |
| **returnZ**                     | Include Z (elevation) values in geometry.                           | `boolean`                 | `returnZ=true`                                                                                                |
| **returnM**                     | Include M (measure) values in geometry.                             | `boolean`                 | `returnM=true`                                                                                                |
| **multipatchOption**            | Controls how multipatch geometries are returned.                    | `string`                  | `multipatchOption=xyFootprint`                                                                                |
| **historicMoment**              | Query layer at a specific moment in history.                        | `integer`                 | `historicMoment=1609459200000`                                                                                |
| **sqlFormat**                   | Defines SQL compatibility level (`standard`, `native`).             | `string`                  | `sqlFormat=standard`                                                                                          |
| **returnTrueCurves**            | Returns true curves instead of densified polylines.                 | `boolean`                 | `returnTrueCurves=false`                                                                                      |
| **supportsQueryData**           | Whether the layer supports data queries (metadata).                 | `boolean`                 | `supportsQueryData=true`                                                                                      |
| **featureEncoding**             | Specifies geometry encoding (`esriDefault`, `geojson`).             | `string`                  | `featureEncoding=geojson`                                                                                     |
